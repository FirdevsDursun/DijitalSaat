# 🕒 Modern Digital Clock & Time Dashboard

![JavaScript](https://img.shields.io/badge/JavaScript-ES6%2B-yellow?style=for-the-badge&logo=javascript)
![HTML5](https://img.shields.io/badge/HTML5-Semantic-orange?style=for-the-badge&logo=html5)
![CSS3](https://img.shields.io/badge/CSS3-Glassmorphism-blue?style=for-the-badge&logo=css3)

Nesne yönelimli JavaScript (ES6+ Class), `Intl` API ve Glassmorphism CSS mimarisi kullanılarak geliştirilmiş modern bir dijital saat ve zaman yönetimi paneli.


---

## 🚀 Özellikler

- **12/24 Saat Formatı:** Tek tıkla dinamik AM/PM ve 24 saat modları arasında geçiş.
- **Canlı İlerleme Barı:** Saniyenin 60 içindeki oranına göre dinamik genişleyen ilerleme barı.
- **Uluslararası Tarih Formatlama:** Tarayıcının `Intl.DateTimeFormat` API'si ile otomatik dil ve yerel tarih/gün gösterimi.
- **Glassmorphism UI:** Modern renk geçişleri (gradient), koyu tema ve yumuşak animasyonlar.

---

## 🛠️ Teknik Bilgiler

- **Architecture:** OOP (ES6 Classes)
- **APIs:** `Intl.DateTimeFormat`, DOM Manipulation
- **CSS:** CSS Custom Properties (`:root`), Flexbox, Glassmorphism
